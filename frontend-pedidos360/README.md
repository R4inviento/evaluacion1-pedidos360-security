# Frontend Pedidos360 - Versión 2.0

Aplicación web en Angular para Pedidos360 con autenticación mediante Microsoft Entra ID (Azure AD) y llamadas protegidas al backend BFF.

## Requisitos

- Node.js (v18+)
- npm

## Instalación

```bash
npm install
```

## Configuración

La configuración de Azure AD y los scopes del backend se encuentran en `src/environments/environment.ts` y `src/app/msal.config.ts`.

## Ejecución

```bash
npm start
```

## Compilación

```bash
npm run build
```
