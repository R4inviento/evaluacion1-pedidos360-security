# Microservicio BFF Pedidos360 - Versión 2.0

Backend for Frontend (BFF) en Spring Boot configurado con OAuth2 Resource Server para validar tokens de Microsoft Entra ID (Azure AD).

## Requisitos

- Java 21
- Maven

## Configuración

La configuración de seguridad se encuentra en `src/main/resources/application.properties`.

## Ejecución

```bash
./mvnw spring-boot:run
```
